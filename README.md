# NetworkWalks Week 3 – PDF Password Cracking Lab

## Overview

This project documents a cybersecurity lab exercise involving the
recovery of a password-protected PDF using NetworkWalks cybersecurity tools.

The exercise was completed in an authorized lab environment for educational
and cybersecurity training purposes.

## Objective

The objectives of this lab were to:

- Extract a crackable hash from a password-protected PDF.
- Use the extracted PDF hash with a password-cracking tool.
- Perform a dictionary attack using the provided built-in wordlist.
- Document the process and results using GitHub.

## Tools Used

- Windows laptop
- NetworkWalks Hash Calculator
- NetworkWalks Password Cracker
- Built-in 100-word dictionary
- GitHub

## Methodology

### 1. PDF Hash Extraction

The password-protected PDF was uploaded to the NetworkWalks Hash Calculator.
The tool identified the PDF as encrypted and generated a crackable PDF hash.

### 2. Hash Input

The extracted PDF hash was copied into the NetworkWalks Password Cracker.

### 3. Dictionary Attack

The built-in 100-password dictionary was selected and the cracking process
was started.

### 4. Result

The password-cracking process successfully identified the matching password
after 91 attempts.

## Ethical Consideration

This exercise was performed in an authorized training environment for
educational purposes. Password-cracking techniques should only be used
against systems or files for which you have explicit authorization.
